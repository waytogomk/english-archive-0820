# MK ENGLISH ARCHIVE MVP

모바일 영어 테스트 앱의 프론트엔드 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 로컬 서버를 쓰려면 Python이 설치된 환경에서 다음을 실행합니다.

```powershell
python -m http.server 4173
```

## 포함된 기능

- 세화여중 기말 단어 퀴즈 샘플
- 문법/챕터북 과정 진입 화면
- 시험지 업로드 및 출제 구조 분석 UI
- 유사 모의고사 생성과 교사 검수 흐름
- 모바일 하단 내비게이션

현재 시험지 분석 및 문제 생성은 UI 프로토타입입니다. 실제 서비스에서는 OCR, 문제 구조화, 생성 모델, 정답 검증, 관리자 검수, 사용자 인증과 데이터베이스 연결이 필요합니다.
